Texte arabe du Coran (ʿuthmānī)

Le texte intégral en graphie ʿuthmānī (Médine) est la numérisation publiée par l'Encyclopédie du Noble Coran (quranenc.com), produite par le Complexe du Roi Fahd pour l'impression du Noble Coran (KFGQPC), initialement obtenue via risan/quran-json puis normalisée pour correspondre à la référence canonique du KFGQPC (text_qpc_hafs).

  • Licence : conditions de libre réutilisation de quranenc.com / KFGQPC — attribution au KFGQPC et à QuranEnc.com, contenu non modifié, version citée. Pas une licence Creative Commons (ni CC BY-SA ni partage à l'identique) et pas dans le domaine public.
  • Modifications : normalisé pour correspondre à la référence canonique du KFGQPC (text_qpc_hafs) ; non modifié par rapport à cette référence.

Traduction française

Le sens français est la traduction du Dr Nabil Rudwan, publiée par le Centre Noor International, fournie par l'Encyclopédie du Noble Coran (quranenc.com) — clé de traduction french_montada, version V1.0.0. C'est une traduction moderne réalisée pour le projet de libre diffusion Rouwwad / QuranEnc.

  • Licence : rediffusion autorisée avec attribution claire à l'éditeur (Centre Noor International) et à QuranEnc.com, sans modification, en citant la version (V1.0.0).
  • Modifications : aucune — intégré octet pour octet sans modification, y compris les appels de note en ligne (p. ex. [1]) et le texte intégral des notes, qui sont affichés dans le lecteur. La source ajoute le numéro de chaque verset (« 1. … ») ; l'application retire ce préfixe redondant à l'affichage, car elle possède son propre marqueur de verset.

Traduction anglaise

Le sens anglais est The Meaning of the Glorious Koran (1930) de Marmaduke Pickthall, provenant de Tanzil.net.

  • Licence : domaine public (le traducteur est mort en 1936 ; l'œuvre de 1930 est entrée dans le domaine public dans ses principales juridictions en 2026).
  • Modifications : aucune — intégré octet pour octet, sans modification.

Logiciel

Le calcul des heures de prière utilise adhan (batoulapps). Le relèvement de la qibla est calculé dans l'application même, par la trigonométrie sphérique classique (grands cercles).

  • Licence : MIT.

Le stockage clé-valeur sur l'appareil utilise react-native-mmkv (© Marc Rousavy), qui embarque le noyau MMKV de Tencent.

  • Licence : MIT (surcouche) ; le noyau MMKV embarqué est Copyright (C) 2018 THL A29 Limited, une société Tencent — licence BSD 3-Clause.

Les widgets d'écran d'accueil Android sont rendus avec react-native-android-widget (sAleksovski).

  • Licence : MIT.

Awaab est construit avec React Native et Expo (MIT) et d'autres modules open source ; React Native embarque en outre des composants natifs tiers (p. ex. Folly — Apache 2.0, glog/double-conversion — BSD 3-Clause, Boost — BSL-1.0, Hermes — MIT) sous leurs licences respectives.
