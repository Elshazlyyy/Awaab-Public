Summary

Awaab is built from openly licensed content and software. Every third-party source below is bundled unmodified except where noted below and credited per its license. The full SIL Open Font License text is available at OFL.txt.

Qur'an Arabic text (Uthmānī)

The full Uthmānī (Madinah) script text is the digitization published by The Noble Qur'an Encyclopedia (quranenc.com), produced by the King Fahd Glorious Qur'an Printing Complex (KFGQPC), initially sourced via risan/quran-json and normalized to match the KFGQPC canonical reference (text_qpc_hafs).

  • License: quranenc.com / KFGQPC free-use redistribution terms — attribution to KFGQPC & QuranEnc.com, content unmodified, version cited. Not Creative Commons (no CC BY-SA / ShareAlike) and not public domain.
  • Modifications: normalized to match the KFGQPC canonical reference (text_qpc_hafs); unmodified relative to that reference.

English translation

The English meaning is Marmaduke Pickthall's The Meaning of the Glorious Koran (1930), sourced from Tanzil.net.

  • License: public domain (the translator died in 1936; the 1930 work entered the public domain in its principal jurisdictions by 2026).
  • Modifications: none — bundled byte-for-byte unmodified.

French translation

The French meaning is the translation by Dr. Nabil Rudwan, issued by Noor International Center, sourced from The Noble Qur'an Encyclopedia (quranenc.com) — translation key french_montada, version V1.0.0. It is a modern translation created for the Rowwad / QuranEnc free-distribution project.

  • License: free to redistribute with clear attribution to the publisher (Noor International Center) and QuranEnc.com, unmodified, citing the version (V1.0.0).
  • Modifications: none — bundled byte-for-byte unmodified, including the inline footnote markers (e.g. [1]) and the full footnote text, which are shown in the reader. The source prepends each verse's number ("1. …"); the app strips that redundant prefix at display time, since it shows its own verse marker.

Software

Prayer-time calculations use adhan (batoulapps). The qibla bearing is computed in-app with standard great-circle (spherical) math.

  • License: MIT.

On-device key-value storage uses react-native-mmkv (© Marc Rousavy), which embeds Tencent's MMKV Core.

  • License: MIT (wrapper); the embedded MMKV Core is Copyright (C) 2018 THL A29 Limited, a Tencent company — BSD 3-Clause License.

Android home-screen widgets are rendered with react-native-android-widget (sAleksovski).

  • License: MIT.

Awaab is built with React Native and Expo (MIT) and other open-source modules; React Native additionally embeds third-party native components (e.g. Folly — Apache 2.0, glog/double-conversion — BSD 3-Clause, Boost — BSL-1.0, Hermes — MIT) under their respective licenses.
